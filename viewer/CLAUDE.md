# CLAUDE.md — viewer

`gakumas-data-viewer`: 学マス コミュ文字起こしビューア（React + Vite + TypeScript の SPA）。
このディレクトリで作業する AI エージェント向けの規約。

## アイコン

**アイコンは [lucide-react](https://lucide.dev/) に統一する。** 絵文字やテキスト記号（「！」等）、
SVG の手書き埋め込みでアイコン相当のものを表現しない。今後アイコンが必要になった場合も
`lucide-react` から探して使うこと。

例: `LineView.tsx` の要確認マークは `lucide-react` の `Info` を使用している。
